# Экраны и навигация

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **навигация** — `нижние вкладки` · `боковое меню` · `один экран + модальные окна` · `стек` (экран за экраном).
- **вкладки** — названия по порядку (3–5 штук). Иконку к каждой — в заметке экрана.
- **онбординг** — приветственные слайды при первом запуске.
- **ориентация** — `портретная` · `альбомная` · `любая`.
- **deep_links** — открытие экранов по ссылке `myapp://order/123` (из писем, пушей).

## Все экраны

Каждый экран — заметка в папке **Экраны** (шаблон: `_Шаблоны/Шаблон экрана`). Список:

| Экран | Где | Вход нужен | Заметка |
| --- | --- | --- | --- |
| Главная | вкладка | нет | [[Экраны/Главная]] |
| «…» | вкладка / стек / модальное | да / нет | [[Экраны/…]] |

## Переходы

Схема — в [[Экраны и переходы.canvas]]: карточка = экран, стрелка = переход (подпись — что нажали).

## Общие элементы

- Шапка: «заголовок, кнопка назад, действие справа»
- Пустые состояния, загрузка (скелетоны), ошибка сети с «Повторить» — [x] на всех списках
- Модальные окна и шторки снизу: «фильтры, подтверждение удаления, выбор даты»
- Жесты: «свайп для удаления, потянуть для обновления»
