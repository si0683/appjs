# Пользователи и безопасность

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **вход** — `нет` · `по желанию` (гость + вход позже) · `обязательно`.
- **способы_входа** — `почта + пароль` · `код на почту` · `код по SMS` · `Яндекс ID` · `VK ID` · `Google` · `Apple` (в iOS обязателен, если есть любой внешний вход).
- **роли** — `пользователь`, `менеджер`, `админ`… (что может каждая — таблица ниже).
- **персональные_данные** — что собираем: `имя`, `телефон`, `почта`, `адрес`, `фото`… Для РФ — согласие и политика по 152-ФЗ, данные россиян — на серверах в РФ.
- **двухфакторная** — код из приложения-аутентификатора при входе.
- **соглашения** — `политика конфиденциальности`, `пользовательское соглашение`, `оферта`.

## Безопасность

- Секреты (ключи API, пароли БД) — только в `.env` на сервере, не в коде и не в `EXPO_PUBLIC_*` (их видно в приложении).
- Токены — только в expo-secure-store.
- Удаление аккаунта по просьбе пользователя: [ ] нужно (обязательно для App Store и Google Play, если есть регистрация)
