# Качество и аналитика

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **устройства** — на чём обязательно проверить.
- **доступность** — подписи у кнопок-иконок для экранного диктора, крупный шрифт не ломает вёрстку, контраст.
- **метрики_успеха** — что считаем успехом через месяц: «100 установок», «конверсия в заявку 3 %», «30 % дошли до 3 уровня».

## Обязательное качество

- Учтены «чёлка», клавиатура и жесты «назад»; работает в светлой и тёмной теме
- Пустые состояния, загрузка, ошибки — понятные, с выходом
- `npm run check` зелёный; тесты на правила и расчёты
