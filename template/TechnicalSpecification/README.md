# Техническое задание: мобильное приложение

Сначала ТЗ — потом код. Эта папка — хранилище **Obsidian**: заполните заметки по порядку, и ИИ-ассистент развернёт проект на стеке **Expo SDK 58 · Expo Router · React Native Reusables · Uniwind (Tailwind 4) · Lucide · TanStack Query · zustand · react-hook-form + zod · Drizzle + expo-sqlite · i18next · EAS** без лишних вопросов.

## Как заполнять

1. Установите [Obsidian](https://obsidian.md) (бесплатно) → «Открыть папку как хранилище» → выберите эту папку `TechnicalSpecification`.
2. Откройте [[00 Паспорт]] и идите по ссылкам сверху вниз: 01 → 13. Каждая заметка — один раздел ТЗ.
3. **Поля вверху заметки** (свойства) — короткие ответы: цвета `#7c3aed`, языки, где хранится база, да/нет. Заполняйте их в первую очередь.
4. **Текст ниже** — подробности: отмечайте `[x]` нужное, заменяйте `«…»` своим, лишнее удаляйте.
5. Повторяющиеся вещи (экраны, таблицы данных) — отдельные заметки в папках. Новая: скопируйте шаблон из `_Шаблоны` (или команда Obsidian «Шаблоны: вставить шаблон»).
6. Карты: **Карта ТЗ.canvas** — всё ТЗ на одном экране, **Экраны и переходы.canvas** — схема переходов. Двойной клик по пустому месту — новая карточка, перетащите заметку из списка слева — карточка-ссылка, тяните от края карточки — стрелка.
7. Когда в [[12 Этапы и готовность]] отмечены все пункты «ТЗ готово» — отдавайте ИИ.

Незнакомый термин или не знаете, что выбрать — оставьте поле пустым: ИИ предложит вариант и запишет его в [[13 Решения и вопросы]].

## Как отдать ИИ

Положите папку в проект (или создайте проект — в нём она уже есть) и напишите ассистенту (Claude Code, Cursor, Codex…):

> Прочитай TechnicalSpecification/ (начни с README.md и 00 Паспорт.md, затем все заметки, папки и .canvas). Задай вопросы по пустым и противоречивым местам, покажи план этапов и после моего «ок» разверни проект.

## Для ИИ-ассистента: как читать это ТЗ

- Порядок: `00 Паспорт.md` → `01`…`13` → папки (Экраны, Данные) → `.canvas` (JSON: `nodes` — карточки, у `type: "file"` поле `file` — путь к заметке; `edges` — стрелки `fromNode → toNode`, подпись в `label`).
- Свойства YAML вверху заметок — обязательные решения; текст ниже — уточнения. При противоречии спроси.
- Пустое поле или `«…»` — прими разумное решение по стеку шаблона и запиши его в `13 Решения и вопросы.md` (дата, решение, почему).
- Проект создаётся командой `npm create appjs@latest my-app`; флаги: `--id=<id приложения>` из [[00 Паспорт]]. Если проект уже создан — работай в нём, правила стека в `AGENTS.md`.
- Цвета, шрифты, скругления из `02 Дизайн.md` — в токены темы, а не в код компонентов. Все строки интерфейса — в переводы по `03 Языки и тексты.md`.
- Делай по этапам из `12 Этапы и готовность.md`; после каждого этапа отмечай в нём выполненное.
- Изменилось решение по ходу работы — обнови ТЗ (нужную заметку и `13 Решения и вопросы.md`), чтобы ТЗ оставалось правдой о проекте.
