# Языки и тексты

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **другие_языки** — каждый отдельным пунктом: `английский`, `казахский`… Пусто — только основной.
- **язык_по_умолчанию** — `как в системе` (язык телефона) или конкретный.
- **тон** — `дружелюбный` · `деловой` · `весёлый` · `нейтральный`.
- **обращение** — `на «вы»` · `на «ты»`.

Где живут тексты в проекте: `src/i18n/locales/ru.json` (база) + `en.json` …, остальные языки грузятся по требованию; язык телефона определяется сам (expo-localization), переключатель — в настройках; название приложения и тексты разрешений — `locales/<язык>.json` в корне; переводчикам — `npm run i18n -- export` (CSV), обратно — `import`. В коде строк нет — только ключи перевода.

- **регионы** — страны и рынки: `Россия`, `СНГ`, `Европа`, `США`, `Ближний Восток`, `весь мир`. От них зависят языки, валюты, правила магазинов и законы о данных (152-ФЗ, GDPR).
- **письмо_справа_налево** — `true`, если среди языков арабский, иврит, фарси, урду: интерфейс зеркалится (уже поддержано, приложение перезапускается при смене).
- **валюта_по_умолчанию / часовой_пояс** — `как в телефоне` или конкретные (`USD`, `Europe/Moscow`). Даты, числа и деньги форматируются по языку и региону телефона (Intl).
- Новый язык: `npm run i18n -- add de` → перевести → добавить в `LANGUAGES` в `src/i18n/index.ts`. Проверка ключей — `npm run i18n -- check`.

- Даты: «04.11.2026 / 4 ноября»
- Валюта: «₽, 1 990 ₽»
- Числа: «1 000 / 1,5»
- Множественное число: «1 заметка, 2 заметки, 5 заметок» — уже работает в i18next
