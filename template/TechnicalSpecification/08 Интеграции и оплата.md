# Интеграции и оплата

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **оплата** — товаров и услуг вне приложения: `нет` · `ЮKassa` · `CloudPayments` · `Stripe`.
- **покупки_в_приложении** — цифровое внутри приложения (подписка, премиум): `нет` · `RevenueCat` (App Store + Google Play). Правило магазинов: цифровое — только через их оплату (комиссия 15–30 %).
- **аналитика** — `AppMetrica` · `Firebase Analytics` · `PostHog` · `нет`.
- **ошибки** — `Sentry` · `нет`.
- **карты** — `Яндекс Карты` · `Google Maps` · `нет`.
- **другие_сервисы** — «Telegram-бот, CRM, почта, SMS-шлюз…»
- **торговля на бирже** — реальные ордера требуют API-ключей: ключи храним ТОЛЬКО на своём сервере, приложение говорит с сервером. В шаблоне — бумажная торговля (сделки в журнал).

Модули с нативным кодом (RevenueCat, AppMetrica, Яндекс Карты) не работают в Expo Go — нужна своя dev-сборка (`npm run build:dev`). ИИ должен предупредить заранее.
