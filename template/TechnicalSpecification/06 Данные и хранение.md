# Данные и хранение

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **где_хранятся_данные** — `на телефоне` (работает без интернета, данные теряются при удалении приложения) · `на сервере` (данные везде, нужен интернет и сервер) · `телефон + сервер` (офлайн + синхронизация).
- **локальная_база** — `SQLite (Drizzle)` — таблицы, уже в шаблоне · `ключ-значение` — только настройки · `нет`.
- **бэкенд** — флаг установщика `--backend`:
  - `none` — без сервера: данные на телефоне, котировки напрямую с биржи (сервер можно добавить позже);
  - `server` — **свой сервер** (папка `server/`): Node + Hono, PostgreSQL, Redis, BullMQ, Better Auth, WebSocket; Docker-образ публикуется в GitHub Container Registry; для большой нагрузки, своей логики, торговых ключей бирж;
  - `supabase` — **Supabase**: облачная база, вход, файлы, realtime без своего сервера; быстрее старт, меньше контроля;
  - уже есть свой API — `none` + `адрес_api` (в `.env` как `EXPO_PUBLIC_API_URL`).
- **синхронизация** — `нет` · `при запуске` · `в реальном времени`; кто прав при конфликте: «последнее изменение / сервер».
- **рыночные_данные** — котировки и свечи: `нет` · `Binance` (публичные, без ключей — уже в шаблоне) · `другая биржа` (Bybit, OKX, MOEX… — адаптер по образцу `src/features/market/binance.ts`) · `свой сервер`. Без сети шаблон сам переходит на демо-данные.
- **файлы_и_фото** — `нет` · `на телефоне` · `в облаке` (S3, Supabase Storage).

Как это ложится на шаблон: таблицы — `src/db/schema.ts` (Drizzle + expo-sqlite), настройки — zustand + key-value, токены и пароли — только expo-secure-store, запросы к серверу — TanStack Query + `api()` из `src/lib/api.ts`.
