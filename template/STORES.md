# Требования магазинов приложений

Правила Google Play, App Store, RuStore и других магазинов — со ссылками только на официальные источники. Цель: чтобы приложение с первого дня делалось так, как его примут, а не переделывалось перед публикацией.

> Проверено по официальным страницам **04.11.2026**. Магазины меняют правила несколько раз в год — перед каждой публикацией откройте ссылки ниже и сверьте даты.

## Как пользоваться

1. **До кода:** в `TechnicalSpecification/00 Паспорт.md` отметьте платформы и магазины. Под них и пишется приложение.
2. **Во время работы:** вход, оплата, сбор данных, разрешения (камера, геолокация) — сначала проверьте раздел нужного магазина ниже.
3. **Перед отправкой:** пройдите [чек-лист](#чек-лист-перед-отправкой).

## Что уже настроено в шаблоне

| Требование                                               | Как в шаблоне                                                                               | Где                        |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------- | -------------------------- |
| Google Play: целевой API 36 с 31.08.2026                 | Expo SDK 58: `targetSdk 36`, `compileSdk 37`, `minSdk 24` (Android 7.0)                     | значения React Native 0.88 |
| RuStore: работа на Android 8.0+                          | `minSdk 24` — запускается с Android 7.0                                                     | —                          |
| App Store: iOS 13 или новее                              | минимальная iOS — 15.1                                                                      | значения React Native 0.88 |
| App Store: сборка в Xcode 26 / SDK iOS 26 (с 28.04.2026) | сборка в облаке EAS — проверьте образ сборки (`image` в `eas.json`), Mac не нужен           | `eas.json`                 |
| Google Play: формат AAB                                  | профиль `production` собирает AAB, `preview` — APK для тестировщиков и RuStore              | `eas.json`                 |
| App Store: экспортное шифрование                         | `usesNonExemptEncryption: false` (только HTTPS)                                             | `app.json` → `ios.config`  |
| Уникальный id приложения                                 | `ios.bundleIdentifier`, `android.package` — задаются `--id` при создании, потом не меняются | `app.json`                 |
| Номер сборки растёт сам                                  | `autoIncrement` + `appVersionSource: remote`                                                | `eas.json`                 |
| Нет отладочной подписи в релизе                          | EAS подписывает релизным ключом, `debuggable` выключен                                      | EAS                        |

Чего в шаблоне **нет** и что нужно сделать под свой проект: политика конфиденциальности (страница на сайте + ссылка в приложении), удаление аккаунта (если есть регистрация), анкеты о данных в консолях магазинов, иконка и скриншоты.

## Чек-лист перед отправкой

**Для всех магазинов**

- [ ] `app.json`: своё `name`, `ios.bundleIdentifier`, `android.package`, `version`; иконка и заставка — свои
- [ ] Политика конфиденциальности: страница в интернете + пункт в приложении (Настройки); для RuStore — на русском
- [ ] Есть регистрация → есть удаление аккаунта в приложении (Google Play — ещё и по ссылке)
- [ ] Каждое разрешение (камера, геолокация, контакты…) действительно нужно и объяснено пользователю
- [ ] Платные цифровые функции — через покупки магазина (App Store, Google Play)
- [ ] Тестовый аккаунт для проверяющих, если есть вход
- [ ] `npm run check` зелёный, приложение не падает на слабом телефоне без интернета

**Google Play**

- [ ] Целевой API соответствует текущему сроку (Expo SDK 58 — API 36)
- [ ] Анкеты: Data safety, контент-рейтинг, целевая аудитория, реклама
- [ ] Название до 30 символов, без эмодзи и КАПСА
- [ ] Новый личный аккаунт — закрытый тест 12 человек × 14 дней пройден

**App Store**

- [ ] Сборка на Xcode 26 / SDK iOS 26 (образ EAS)
- [ ] Манифест приватности и «этикетки» приватности в App Store Connect
- [ ] Ответы на вопросы возрастного рейтинга
- [ ] Название и подзаголовок до 30 символов, ключевые слова до 100

**RuStore**

- [ ] Иконка 512×512 без прозрачности, скриншоты с реальной работой
- [ ] Политика на русском — в карточке и в приложении
- [ ] Указан контакт разработчика

## Как публиковать из этого проекта

```bash
npm run build:preview   # APK/ad-hoc для тестировщиков и RuStore
npm run build:prod      # AAB для Google Play, IPA для App Store
npm run submit          # отправка в App Store Connect / Google Play
```

Документация Expo: [EAS Submit](https://docs.expo.dev/submit/introduction/) · [версии и номера сборок](https://docs.expo.dev/build-reference/app-versions/) · [настройки app.json](https://docs.expo.dev/versions/latest/config/app/).
