# Публикация

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

- **магазины** — берутся из [[00 Паспорт]] (поле `магазины`); **ещё_магазины** — если позже добавятся новые.
- Требования каждого магазина и чек-лист перед отправкой — [STORES.md](../STORES.md) (официальные ссылки).
- **аккаунт_expo** — логин на expo.dev (сборки EAS в облаке, Mac не нужен).
- **apple_developer** — аккаунт $99/год (нужен для App Store и TestFlight). **google_play_console** — $25 один раз.
- **обновления_по_воздуху** — исправления JS-кода без магазина (`npm run update`, EAS Update).

## Как выпускаем

1. Тест у себя — Expo Go (`npm start` / `npm run tunnel`).
2. Тестировщикам — `npm run build:preview` (APK для Android, ad-hoc / TestFlight для iOS).
3. В магазины — `npm run build:prod` → `npm run submit`.
