# Паспорт проекта

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

## Поля

- **название** — то, что увидят люди.
- **тип** — одно из: трекер / планировщик · каталог / магазин · запись на услуги · соцсеть / чат · контент / курсы · кабинет моего сервиса · утилита · обучение.
- **статус** — `черновик` → `на проверке` → `готово` (можно отдавать ИИ) → `в разработке`.
- **id_приложения** — уникальный id для App Store / Google Play / RuStore: `ru.компания.приложение`, латиница. Потом не меняется.

## Платформа — обязательно

> [!important] Заполните до начала разработки
> Под какие платформы и магазины пишется приложение. Без этих полей ИИ-ассистент не начинает работу: от платформы зависят библиотеки, вход, оплата, разрешения и формат сборки.

| Поле | Варианты | По умолчанию |
| --- | --- | --- |
| **платформы** | `Android` · `iOS` (оба — из одного кода) | Android и iOS |
| **магазины** | `Google Play` · `App Store` · `RuStore` · `Huawei AppGallery` · `Samsung Galaxy Store` · `Amazon Appstore` · `F-Droid` · `только APK (сайт, корпоративная раздача)` | Google Play, App Store, RuStore |
| **устройства** | `телефон` · `планшет` · `ТВ` | телефон |
| **веб_версия** | `true` — нужен ещё и сайт-версия (Expo Web) · `false` — веб только для отладки | false |
| **стек** | не менять: **Expo SDK 58 / React Native** — это НЕ Flutter, НЕ Kotlin/Swift, НЕ сайт | — |
| **минимальная_android / минимальная_ios** | 7.0 (API 24) и 15.1 — минимум шаблона; выше — только если нужно | 7.0 / 15.1 |

Правила выбранных магазинов (длина названия, иконка, политика конфиденциальности, удаление аккаунта, покупки, сроки проверки) — в [STORES.md](../STORES.md): ссылки только на официальные источники. Важно заранее:

- **App Store** — цифровые товары и подписки только через покупки Apple; при входе через Google/VK — нужен и вход, отвечающий правилу 4.8 (например, Sign in with Apple).
- **Google Play** — новый личный аккаунт: закрытый тест 12 человек × 14 дней перед публикацией.
- **RuStore** — политика конфиденциальности на русском, в карточке и внутри приложения.
- **F-Droid** — только открытый код без несвободных SDK (реклама, аналитика, Google-сервисы).
