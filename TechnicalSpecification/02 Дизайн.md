# Дизайн

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

## Поля

| Поле | Что писать |
| --- | --- |
| стиль | минимализм как у Apple · дружелюбный яркий · строгий деловой · премиум |
| тема | `светлая` · `тёмная` · `светлая и тёмная` (переключатель) · `системная` (как в телефоне) |
| цвета | HEX `#7c3aed`. Основной — кнопки и ссылки, акцентный — выделение, бейджи. Пусто — ИИ подберёт под нишу и запишет в [[13 Решения и вопросы]] |
| шрифты | `системный` · название из [Google Fonts](https://fonts.google.com) (Inter, Manrope, Montserrat…) · пиксельный (Press Start 2P) |
| скругление | `0px` строгие · `6px` · `10px` мягкие · `16px` крупные |
| иконки | `Lucide` ([lucide.dev](https://lucide.dev) — уже в стеке) · свои SVG |
| анимации | `нет` · `сдержанные` (появление, нажатия) · `выразительные` (переходы, параллакс, счётчики) |


Цвета и шрифты ИИ переносит в токены темы: `src/global.css` (переменные `--color-*` для светлой и тёмной темы) и `src/lib/theme.ts` (цвета шапки и вкладок). В компонентах — только токены, без «жёстких» `#hex`, иначе сломается тёмная тема.
