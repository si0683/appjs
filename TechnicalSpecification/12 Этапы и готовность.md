# Этапы и готовность

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при развёртывании. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[13 Решения и вопросы]]».

## ТЗ готово, когда

- [ ] [[00 Паспорт]]: название, тип, id приложения
- [ ] [[02 Дизайн]]: цвета, шрифт, тема
- [ ] [[03 Языки и тексты]]: языки
- [ ] [[04 Экраны и навигация]]: все экраны перечислены, у главных есть заметки
- [ ] [[05 Функции]]: главный сценарий по шагам
- [ ] [[06 Данные и хранение]]: где хранятся данные
- [ ] [[10 Публикация]]: куда выкладываем
- [ ] Открытые вопросы в [[13 Решения и вопросы]] закрыты или помечены «решит ИИ»

Всё отмечено → поставьте `тз_готово: true` и статус `готово` в [[00 Паспорт]].

1. [ ] **Этап 1.** Каркас: навигация, тема, все экраны-заглушки — срок: «…»
2. [ ] **Этап 2.** Данные: таблицы, запросы, сервер — срок: «…»
3. [ ] **Этап 3.** Функции главного сценария — срок: «…»
4. [ ] **Этап 4.** Остальные функции, вход, уведомления — срок: «…»
5. [ ] **Этап 5.** Полировка, тесты, сборка preview — срок: «…»
6. [ ] **Этап 6.** Магазины: карточки, build:prod, submit — срок: «…»
