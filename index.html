Приложение для Android и iOS одной командой

Один код на TypeScript — два магазина. Биржевые графики, точная математика, статистика и экспорт — уже внутри. Mac не нужен.

Как начать

  1. Создайте проект
    npm create appjs@latest my-app
  2. Откройте на телефоне
    cd my-app && npm start
  3. Меняйте экраны в src/app/QR-код → Expo Go; изменения видны сразу. Не подключается — npm run tunnel.
  4. Соберите для магазинов
    npm run build:prod && npm run submit

ТЗ для нейросети — PROMT.md. Опции: --id=ru.company.app, --no-install, --no-git.
